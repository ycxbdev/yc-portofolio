# YCxBlock101 | Cybersecurity Portfolio

Terminal-style portfolio built with Next.js, TypeScript & Tailwind CSS.

- Terminal Hero with hacking simulation
- Matrix Rain background
- Project showcase
- Skills section
- Contact page

## Tech Stack

- Next.js 15
- TypeScript
- Tailwind CSS v4
- Vercel
